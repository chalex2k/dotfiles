# Neovim

Конфигурация использует
[nvim-tree.lua](https://github.com/nvim-tree/nvim-tree.lua) для отображения дерева
файлов проекта и
[nvim-lspconfig](https://github.com/neovim/nvim-lspconfig) вместе с `gopls` для
навигации по Go-коду.

## Открытие дерева

Откройте Neovim в корне проекта:

```sh
nvim .
```

Нажмите `Space e`, чтобы открыть или скрыть дерево файлов.

## Основные клавиши nvim-tree

Клавиши работают, когда курсор находится в окне дерева:

| Клавиша | Действие |
| --- | --- |
| `Enter` или `o` | Открыть файл или каталог |
| `Tab` | Открыть файл, оставив курсор в дереве |
| `a` | Создать файл или каталог; для каталога завершите имя символом `/` |
| `r` | Переименовать |
| `d` | Удалить с подтверждением |
| `x` | Вырезать |
| `c` | Копировать |
| `p` | Вставить |
| `y` | Скопировать имя файла |
| `Y` | Скопировать относительный путь |
| `gy` | Скопировать абсолютный путь |
| `H` | Показать или скрыть скрытые файлы |
| `R` | Обновить дерево |
| `q` | Закрыть дерево |
| `g?` | Показать все доступные клавиши |

Для разделения окна используйте:

| Клавиша | Действие |
| --- | --- |
| `Ctrl-v` | Открыть файл в вертикальном разделении |
| `Ctrl-x` | Открыть файл в горизонтальном разделении |
| `Ctrl-t` | Открыть файл в новой вкладке |

## Навигация по Go-коду

Для работы навигации должен быть установлен Go language server:

```sh
brew install gopls
```

Откройте Neovim из каталога Go-модуля, в котором находится `go.mod`:

```sh
cd ~/project
nvim .
```

Откройте Go-файл через дерево (`Space e`) или командой `:edit path/to/file.go`.
`gopls` подключится автоматически. Команда `:checkhealth vim.lsp` показывает
состояние LSP и активные серверы.

Клавиши навигации работают в Go-файлах после подключения `gopls`:

| Клавиша | Действие |
| --- | --- |
| `gd` | Перейти к определению |
| `gr` | Найти все использования |
| `gI` | Перейти к реализации интерфейса |
| `K` | Показать документацию символа |
| `Space rn` | Переименовать символ во всём проекте |
| `Space ca` | Показать доступные действия над кодом |
| `[d` | Перейти к предыдущей диагностике |
| `]d` | Перейти к следующей диагностике |

После `gr` найденные использования открываются в списке результатов. Управление
этим списком:

| Команда | Действие |
| --- | --- |
| `Enter` | Открыть выбранный результат |
| `:cnext` | Перейти к следующему результату |
| `:cprevious` | Перейти к предыдущему результату |
| `:cclose` | Закрыть список результатов |

При переходе через `gd` вернуться назад можно клавишами `Ctrl-o`, а снова перейти
вперёд — `Ctrl-i`.

Если навигация не работает:

1. Проверьте, что файл находится внутри Go-модуля с `go.mod`.
2. Выполните `:checkhealth vim.lsp` и убедитесь, что к буферу подключён `gopls`.
3. В терминале выполните `go version` и `gopls version`.

## Применение конфигурации

Запускайте Stow из каталога `dotfiles`:

```sh
cd ~/setup/dotfiles
stow --restow --no-folding --target "$HOME" nvim
```

Файлы в `~/.config/nvim` будут ссылаться на конфигурацию из этого репозитория.
