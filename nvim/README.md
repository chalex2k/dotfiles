# Neovim

Конфигурация использует
[nvim-tree.lua](https://github.com/nvim-tree/nvim-tree.lua) для отображения дерева
файлов проекта.

## Открытие дерева

Откройте Neovim в корне проекта:

```sh
nvim .
```

Нажмите `Space e`, чтобы открыть или скрыть дерево файлов.

## Основные клавиши nvim-tree

Клавиши работают, когда курсор находится в окне дерева:

| Клавиша | Действие |
| --- | --- |
| `Enter` или `o` | Открыть файл или каталог |
| `Tab` | Открыть файл, оставив курсор в дереве |
| `a` | Создать файл или каталог; для каталога завершите имя символом `/` |
| `r` | Переименовать |
| `d` | Удалить с подтверждением |
| `x` | Вырезать |
| `c` | Копировать |
| `p` | Вставить |
| `y` | Скопировать имя файла |
| `Y` | Скопировать относительный путь |
| `gy` | Скопировать абсолютный путь |
| `H` | Показать или скрыть скрытые файлы |
| `R` | Обновить дерево |
| `q` | Закрыть дерево |
| `g?` | Показать все доступные клавиши |

Для разделения окна используйте:

| Клавиша | Действие |
| --- | --- |
| `Ctrl-v` | Открыть файл в вертикальном разделении |
| `Ctrl-x` | Открыть файл в горизонтальном разделении |
| `Ctrl-t` | Открыть файл в новой вкладке |

## Применение конфигурации

Запускайте Stow из каталога `dotfiles`:

```sh
cd ~/setup/dotfiles
stow --restow --no-folding --target "$HOME" nvim
```

Файлы в `~/.config/nvim` будут ссылаться на конфигурацию из этого репозитория.
