# Zsh

Конфигурация активирует [mise](https://mise.jdx.dev/) для автоматического выбора
версий инструментов в зависимости от текущего проекта.

Примените конфигурацию через Stow:

```sh
cd ~/setup/dotfiles
stow --restow --target "$HOME" zsh
```

После первого применения перезапустите shell:

```sh
exec zsh
```

## Версии Go

Установите актуальную Go как версию по умолчанию:

```sh
mise use --global go@latest
```

Закрепите точную версию внутри проекта:

```sh
cd ~/project
mise use go@1.24.6
```

Команда создаст в проекте файл `mise.toml`. После входа в каталог `mise`
автоматически добавит выбранную версию Go в `PATH`.

Полезные команды:

| Команда | Действие |
| --- | --- |
| `mise current` | Показать активные версии |
| `mise ls go` | Показать установленные версии Go |
| `mise ls-remote go` | Показать доступные версии Go |
| `mise use go@VERSION` | Выбрать Go для текущего проекта |
| `mise use --global go@VERSION` | Выбрать Go по умолчанию |
| `mise upgrade go` | Обновить Go в текущей конфигурации |
